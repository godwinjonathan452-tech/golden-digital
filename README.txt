GOLDEN DIGITAL — Starter Website v0.1

WHAT THIS IS
A responsive first website for GOLDEN DIGITAL. It includes:
- A professional landing page
- Feature overview
- A template-based Marketing Studio preview
- Marketplace preview section
- Founder attribution

IMPORTANT
The Marketing Studio in this first version uses simple templates in the browser.
It is NOT connected to a real AI model, user accounts, a database, payments,
product listings, or live advertising. Those features must be developed and
tested in later stages. Do not advertise these planned features as operational.

HOW TO USE ON ANDROID
1. Download and extract golden-digital-starter.zip using your phone's Files app.
2. Open github.com in Chrome and sign in.
3. Create a new public repository named golden-digital.
4. Open the repository, choose Add file > Upload files.
5. Upload index.html, styles.css, app.js and README.txt from the extracted folder.
6. Commit the files.
7. In the repository, open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose the main branch and /(root), then Save.
10. Wait for GitHub Pages to publish. The website address will appear in Settings > Pages.

If the phone interface hides a button, use Chrome's menu and select
"Desktop site".

FREE-TIER NOTE
GitHub Pages can host a static public website for free within its published
limits. This starter does not require paid AI credits or an API key.
A custom domain, real AI API usage, payment processing, database scale,
and Google Play publishing may involve costs later.
