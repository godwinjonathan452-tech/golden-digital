Development Status Rules

- PLANNED: Not yet implemented.
- IN PROGRESS: Currently being developed.
- IMPLEMENTED: Code or functionality has been added.
- TESTED: Functionality has been tested successfully.
- VERIFIED: Implementation and test results have been independently checked.

Never mark a feature as completed without evidence.
